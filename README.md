
# NAVUMSH — The Science of Inheritance

**Explore the science of DNA, genes and inheritance.**

NAVUMSH is an educational website designed to make genetics easier to understand through scientific explanations and interactive learning experiences.

## About the Project

Genetics explains how biological information is stored, expressed and transmitted across generations.

NAVUMSH introduces these concepts through beginner-friendly explanations, interactive experiments and knowledge checks.

## Learning Features

- Introduction to DNA, genes, alleles and chromosomes
- Genetics terminology and fundamental concepts
- Interactive monohybrid Punnett square simulator
- Dihybrid inheritance simulator
- Complete dominance, incomplete dominance and codominance
- X-linked recessive inheritance
- Mitochondrial inheritance
- Polygenic inheritance
- Meiosis stage explorer
- Genetics knowledge quiz

## Important Scientific Note

Genetic predictions shown in NAVUMSH are based on simplified teaching models.

Real inheritance can be influenced by multiple genes, environmental factors, gene interactions and other biological mechanisms.

Dominance does not mean that an allele is more common, stronger or better.

## Project Vision

To make the science of inheritance accessible, interactive and interesting for learners at different levels.
